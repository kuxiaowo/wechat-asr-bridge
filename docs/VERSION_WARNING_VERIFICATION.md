# v0.3.3 版本警告与错误诊断验证

日期：2026-10-21；环境：Windows x64、Python 3.11 conda、PyInstaller 6.20.0。

## 离线测试与窗口检查

- `python -m unittest discover -s tests -p "test_*.py" -q`：83 项测试通过。
- 源码编译检查通过，包含新增的 `diagnostics.py` 和 `native_compat.py`。
- 指纹不同的微信模块只产生警告，模拟原生 agent 仍会加载并完成转写。
- 输入法模块指纹变化时仍按函数特征定位编码器；缺少函数或出现多个匹配时返回实际定位错误。
- JSON、纯文本响应头、失败响应和健康接口都保留版本警告；未处理异常的具体原因与请求 ID 可见。
- 手动转写失败时，完整错误进入可复制的结果区；诊断窗口在 480×280 和 780×460 下显示完整内容及复制按钮。
- 首页和手动转写页在 96/120/144/192 DPI 下的控件边界检查通过。

## 真实客户端检查

源码服务使用仓库合成的 6.28 秒音频验证微信输入法 3.0.0.37，返回 HTTP 200、正确文字及 `server_end_flag`，并同时返回 `unverified_wetype_version` 警告。该次请求约 2.25 秒完成，后续客户端请求持续成功；这不是性能或长期稳定性保证。

微信 4.1.15.56 的只读诊断返回 `ok=true`、`dll_fingerprint_matches=false` 和版本警告。此次没有验证该版微信的原生识别，不宣称其原生地址或对象布局已适配。取消版本拦截不保证任意未来客户端版本兼容。
