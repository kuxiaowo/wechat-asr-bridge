# Windows 免安装窗口版

v0.3.3 提供微信、微信输入法和豆包网页匿名语音三个后端。版本或指纹不匹配只警告，窗口支持完整错误与警告详情。无需安装 Python、conda 或 FFmpeg。

1. 解压整个 `WeChatASRBridge-0.3.3-windows-x64-portable.zip`，保留 `_internal` 文件夹，不能只移动 EXE。
2. 启动 `WeChatASRBridge.exe`，点击「启动服务」。
3. 首页显示三个独立并发池。绿色格子表示占用，空闲格子不填色。
4. 在「手动转写」页选择 model，选择音频或使用合成示例，再点击「开始识别」。
5. 首页可复制 Base URL、model。点击「打开接口文档」在浏览器打开独立 HTML 文档；服务未启动时也能打开离线文档。

## 模型

- `wechat-voice`：微信桌面端，需已登录并保持可用；参考版本 4.1.13.65，其他版本只警告后继续尝试。
- `wetype-voice`：微信输入法，需对应进程和组件可用；已验证 3.0.0.34 和 3.0.0.37，按函数特征定位编码器，版本差异只警告。
- `doubao-voice`：普通豆包网页游客会话，不需要从浏览器获取登录凭据。

应用可以在微信没有运行时启动并使用其他后端。音频会发送到所选服务的服务端；不会发送给 OpenAI。单个上传文件最大 25 MiB，WAV/MP3 等格式由内置 FFmpeg 完整转换；当前返回最终文字，不提供流式结果。

## 设置与接口

首页「诊断详情」显示后台请求的完整错误码、异常原因、请求 ID 和版本警告，并支持复制。手动识别失败时，结果区也显示可复制的完整错误。版本警告不会把成功转写改成失败；原生调用、音频或网络实际失败时仍会返回具体错误。

默认 Base URL 为 `http://127.0.0.1:8765/v1`。设置中可调整端口、本地 API Key 和各后端并发数。各模型默认并发均为 4，可分别调整为正整数；各模型独立调度，超出本池并发数的请求排队。旧版已保存的配置保留。大量格子会分页显示；显示分页不会影响调度。

更改自有服务的端口、密钥或并发数时，会等待已有识别及清理完成，然后重启服务。在设置中勾选「启用 API Key 鉴权」才会要求密钥；关闭时，客户端任意 Key 或不传 Key 都被忽略，修改闲置 Key 不会重启服务。旧版已设置密钥的安装会保留鉴权。API Key 使用 Windows DPAPI 加密，只有当前 Windows 用户能解密。旧版端口与密钥设置继续保留。

接口文档详见随包 `docs/api.html`（在 `_internal/docs/` 中）或运行中的 `/docs`。该页面说明 file、model、response_format、stream、temperature、鉴权、示例和错误格式。

## 托盘和退出

关闭窗口会隐藏到托盘，已启动的服务继续运行。托盘菜单可以恢复窗口或正常退出；退出会等待请求完成并停止自有服务，不会强杀微信或输入法。

其他程序启动的兼容服务只能查看和调用，请使用原启动程序调整和停止它。旧版仅提供单个微信后端的服务不能冒充新版统一服务；如占用同一端口，请正常停止旧服务或为新版选择其他端口。

运行文件在 `%LOCALAPPDATA%\WeChatASRBridge\runtime`，点击「运行日志」可打开。ZIP 不含账号信息、用户录音或识别结果；只有手动另存文字时才保存结果。

原生连接意外断开或清理失败后，对应客户端可能需退出再重新启动，程序不会冒险卸载仍被原生代码引用的回调。豆包网页结构及私有协议可能改变。没有经过长时间持续并发压力测试，不能将可配置容量当成稳定性保证。
